# Rolling Greens

Build a golf resort in a **3D realist course view**: claim raw land, terraform it, and construct each hole by hand — while golfers walk, drive carts, and actually play the holes around you.

## Play

```bash
npm install
npm run dev
```

## How to play

1. Arrive at the **clubhouse** on County Rd 7 with a starter **driving range** already hosting live practice swings.
2. **Collect range fees**, then **claim land** — new plots start as **raw meadow**.
3. **Terraform** hills and hollows, **build surfaces** (fairway, green, bunkers, paths), place tee and cup.
4. **Open the hole** for play — guests tee off, walk or cart to their ball, and putt out in the 3D park.
5. Playtest any hole in a full 3D green view with pull-back aiming.
6. Grow **9 → 18 → second 18 (36 holes)** and expand the range.

Drag to orbit, scroll to zoom. Progress saves in the browser.
